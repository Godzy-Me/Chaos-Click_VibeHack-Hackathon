# 💥 Chaos-Click

> A perfectly normal student portal. Until you start clicking.

**Chaos-Click** is a playful, chaotic browser experience built for a hackathon. It starts as a fictional college registration portal and gradually falls apart as you interact with it. Buttons get sneaky, text gets increasingly unhinged, and the website becomes more chaotic the longer you play.

🔗 **Live demo:** https://clickchaos.vercel.app/

## 🎮 What is this?

Imagine trying to finish your college registration while the website slowly loses its mind. That's Chaos-Click.

Explore the fake student portal, click around, try to complete the registration steps, and see how long you can keep things under control. The page is designed to surprise you—sometimes the interface helps, sometimes it absolutely does not.

## ✨ Features

- **Escalating chaos:** Page copy and interface elements change as chaos increases.
- **Uncooperative UI:** Some buttons and navigation elements try to dodge your cursor.
- **Photo-upload mayhem:** Upload a picture and watch the experience get delightfully messy.
- **Interactive gags and popups:** Unexpected reactions keep the portal unpredictable.
- **Visual effects:** Canvas effects and animations add to the chaos.
- **Progression and achievements:** Keep interacting to discover more of the experience.
- **A fictional college portal:** The Quackwell Institute of Technology is completely made up.

## 🕹️ How to play

1. Open the [live demo](https://clickchaos.vercel.app/) or run the project locally.
2. Start exploring the student registration portal.
3. Click buttons, try the registration steps, and experiment with the upload area.
4. Keep going as the site gets more chaotic.
5. Your mission: finish what you came to do. Good luck. 🦆

## 🧰 Built with

- HTML
- CSS
- Vanilla JavaScript
- HTML Canvas for visual effects

No framework or build step is required for the basic local setup.

## 🚀 Run locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

For a smoother development workflow, you can open the folder in VS Code and use the **Live Server** extension to serve `index.html`.

## 🤹 Why?

Because websites are usually expected to behave themselves—and that's boring.

Chaos-Click is a small experimental project about playful interactions, escalating visual chaos, and turning an ordinary task into a ridiculous mini-game.

## ⚠️ Disclaimer

This is a fictional fun project. The college, portal, registration process, and related content are made up. It is not an actual college registration or payment service.
